# AGENTS.md

## Project Overview

`@meltstudio/eslint-config` — Melt Studio's shared ESLint configuration package,
publishing config presets (base, node, react, Next.js, jest) as a single npm
package consumed by other Melt repos.

## Stack

- languages: JavaScript (CommonJS)
- frameworks: none (config-only package; presets target Node, React, and Next.js
  consumers)
- test-runner: none
- package-manager: yarn
- deploy: npm, via semantic-release on merge to `main`

## Verification Commands

- Format: `yarn format` (prettier --write .)
- CI check (format only, no build/test/typecheck): `yarn prettier --check`
- Commit messages: must pass commitlint (`@commitlint/config-conventional`),
  enforced by husky `commit-msg` hook and CI (`_lint_commits.yaml`)

## Reference Examples

- New base ruleset: follow the pattern in `base.js` (plain JS) or `base-ts.js`
  (TypeScript variant)
- New framework preset: follow the pattern in `react-ts.js` (extends
  `base-ts.js`, adds airbnb + react rules) or `nextjs-ts.js` (extends
  `react-ts.js`, adds Next.js rules)
- New test-tooling overrides: follow the pattern in `jest-overrides.js` /
  `jest-react-overrides.js`
- Package entry point: `index.js` re-exports `base-ts.js` as the default config
